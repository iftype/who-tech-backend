## 해석

- 이미 낮다. 에이전트가 push 전에 검사를 손으로 돌렸기 때문이다. 그래서 효과는 CI 실패율보다 **"잊어도 반드시 돈다"와 "CI 전에 몇 번 잡았나"**(훅 로그의 막은 횟수)로 본다
- ②에는 `gh pr update-branch`로 생긴 push도 섞여 있다(코드 수정이 아님)
- 기준값에 없는 것: 커밋 훅 실패(commitlint 100자 등)는 GitHub 기록에 안 남는다. 변경 검사도 커밋 메시지는 보지 않는다

## 도입하며 바로 찾은 것

- 어드민 `tsconfig.json`이 `files: []` + references 묶음이라 `tsc --noEmit -p src/public/admin-spa`는 **아무것도 검사하지 않았다**. 그동안의 로컬 "어드민 tsc 통과"는 빈 검사였고, 실제 타입 검사는 CI `build`(`tsc -b`)에서만 돌았다 → 변경 검사는 `tsconfig.app.json`을 쓴다
- typecheck가 처음 58초 → 증분 정보(`.git/harness/*.tsbuildinfo`)로 15초대
